1. Создай репозиторий на GitHub и загрузи все файлы (включая папку .github).
2. Settings → Pages → Source: Deploy from a branch → main, папка / (root).
3. Actions → "Update carry data" → Run workflow (первый запуск вручную).
4. Сайт: https://<твой-логин>.github.io/<репозиторий>/
(Необязательно) бесплатный ключ OpenDota → Settings → Secrets → OPENDOTA_KEY: больше запросов в сутки.
